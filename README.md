# WAV to MP3 Converter

A small app for converting `.wav` files to `.mp3`.

- macOS: drag-and-drop desktop app
- Windows: standard desktop app
- Linux: portable CLI for any distribution

## macOS / Windows desktop app

1. Download the artifact or release for your operating system.
2. Launch the app.
3. Optional: click **Choose output folder**.
4. Drag one or more `.wav` files into the drop zone, or click **Choose WAV files**.
5. The `.mp3` files are created in the selected output folder. If no output folder is selected, they are created next to the original `.wav` files.

See also: [INSTALL.md](INSTALL.md)

## Linux / CLI

Install from source:

```bash
python3 -m pip install .
wav-to-mp3 ./my-wavs --output-dir ./mp3
```

Or use the Linux binary generated by GitHub Actions:

```bash
tar -xzf wav-to-mp3-linux-x86_64.tar.gz
./wav-to-mp3 ./my-wavs --output-dir ./mp3
```

CLI examples:

```bash
# Convert one file
wav-to-mp3 song.wav

# Convert multiple files
wav-to-mp3 song1.wav song2.wav -o ./mp3

# Convert all WAV files in a folder
wav-to-mp3 ./album --output-dir ./mp3

# Choose the bitrate
wav-to-mp3 ./album -o ./mp3 --bitrate 192k
```

## Requirements

`ffmpeg` must be installed.

```bash
# macOS
brew install ffmpeg

# Windows with Chocolatey
choco install ffmpeg

# Debian/Ubuntu
sudo apt install ffmpeg

# Fedora
sudo dnf install ffmpeg

# Arch
sudo pacman -S ffmpeg
```

## Development

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -e '.[dev]'
pytest -q
```
